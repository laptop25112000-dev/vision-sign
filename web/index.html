ISL Recognition Study

Visual Voice was built as a data collection and machine learning project. Around 50,000 sign samples were processed through MediaPipe, converted into landmark features, cleaned, balanced, trained, and evaluated before being used for live webcam translation.

Problem Statement

Convert Indian Sign Language alphabet gestures into readable and spoken English letters using computer vision and supervised classification.

Research Question

Can hand landmark features classify A-Z signs accurately enough for real-time webcam translation on a normal laptop?

Target Variable

Alphabet class label from A to Z. Each sample is represented by normalized hand landmark coordinates instead of raw pixels.

Data Analysis Used

The project works like a data collector first. Images and webcam frames are collected, MediaPipe extracts hand landmarks, weak frames are rejected, class counts are compared, samples are balanced, and the model is evaluated using train-test split, precision, recall, F1-score, accuracy, confusion matrix, confidence score, and distance-based rejection for unclear signs.

Neural Network Comparison

The current working model is not a neural network. It uses an SVM because the dataset is moderate in size and MediaPipe already converts images into useful hand features. A neural network version could use 128 input neurons, hidden layers such as 64 and 32 neurons, and a 26-class softmax output. Google Translate-style systems use much larger neural networks for language translation, while this project focuses on gesture-to-letter classification.
